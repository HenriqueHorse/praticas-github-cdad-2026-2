# Prática de issue e pull request

Repositório da disciplina Ciência de Dados Aplicada ao Direito I para a atividade de issue e pull request.

## O que fazer aqui

1. Abra uma **issue** explicando, com as suas palavras, o que você entendeu que é uma issue.
2. Faça um **fork** deste repositório. No seu fork, crie na pasta `explicacoes/` um arquivo com o seu nome de usuário do GitHub, como `explicacoes/seu-usuario.md`, explicando o que você entendeu que é um pull request. Depois abra um **pull request** do seu fork para este repositório.
3. Peça ao seu assistente de código que comente na sua issue e no seu pull request, dizendo se a explicação está certa e o que falta. O comentário diz que modelo o escreveu.

O passo a passo está no guia da atividade, no Blackboard.

## Regras

- A issue e o arquivo são escritos por você, sem assistente. O assistente entra só no passo 3.
- Mexa só no seu arquivo.
- Este repositório é público: não escreva nada que você não queira ver publicado.
