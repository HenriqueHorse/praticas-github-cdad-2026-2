# Práticas de GitHub de CDAD-1, 2026/2

Repositório da disciplina Ciência de Dados Aplicada ao Direito I, do Insper, para as atividades que se entregam por issue e pull request. Os passos de cada uma estão no guia da atividade, no Blackboard, e a regra de pontuação está nos slides.

## Atividade 1: issue e pull request

Até o início da aula de quarta, 21/10.

1. Abra uma **issue** explicando o que é uma issue, do jeito que você explicaria a um advogado que nunca programou.
2. Faça um **fork** deste repositório. No seu fork, crie o arquivo `explicacoes/seu-usuario.md`, com o seu nome de usuário do GitHub, explicando o que é um pull request para o mesmo advogado. Depois abra um **pull request** do seu fork para este repositório.
3. Peça ao seu assistente de código que comente na sua issue e no seu pull request, dizendo se a explicação está certa e o que falta. O comentário termina dizendo que modelo o escreveu.

## Atividade 2: uma raspagem com o juscraper

Até o início da aula de terça, 27/10.

No seu fork, crie a pasta `raspagens/seu-usuario/` com o código da sua raspagem (`.py` ou `.ipynb`) e o arquivo `.csv` que ele salvou. Depois abra um **pull request** do seu fork para este repositório.

## Regras

- As explicações da atividade 1 são escritas por você, sem assistente. O assistente entra só no passo 3.
- Mexa só nos seus arquivos: `explicacoes/seu-usuario.md` e a pasta `raspagens/seu-usuario/`.
- Este repositório é público: não escreva nada que você não queira ver publicado.
